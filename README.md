# Good Pets

Good Pets is a pet-care booking application for dog and cat owners in Victoria Island, Lagos. It lets customers book grooming, daycare, and boarding services, register and manage their pets, and pay through a secure online checkout.

This repository contains the Task 2 scaffold: a Next.js application with PostgreSQL-backed customer registration, built as part of a portfolio project.
