## Result

- Both hashes are different, despite using the same password.
- Both hashes successfully verify against the original password.
- The encoded hashes contain different salt values.
- Argon2id stores the salt and algorithm parameters in the encoded hash, allowing verification without separately storing the salt.

This demonstrates why password hashing is not equivalent to simply encrypting or hashing a password with a fixed deterministic digest.
