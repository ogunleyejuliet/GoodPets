# Nested-Folder Failure Evidence

**Date:** 28 October 2026

## Objective
Demonstrate what happens when a server file is executed from the wrong working directory.

## Starting directory
`C:\Users\hp\Desktop\GoodPets`

## Commands executed
```bat
mkdir temp-nested-test
cd temp-nested-test
node server.js
```

## Actual result
Node.js returned the error `MODULE_NOT_FOUND` because it could not locate:

`C:\Users\hp\Desktop\GoodPets\temp-nested-test\server.js`

## Conclusion
The command failed because `server.js` is located in the GoodPets project root, not in the nested test directory. This confirms that the working directory matters when executing a file by a relative path.
